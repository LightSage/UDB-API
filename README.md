# UDB-API

An API that wraps the [Universal DB json file](https://db.universal-team.net/data/full.json), built with FastAPI! 💪

## Why use UDB-API?

It adds search functionality with filter(s)! You can also query the API for a random app. 

The best part about UDB-API is that it's fully typed! No more second guessing what keys exist or don't exist!

### Where do I go to use the API?

You can find the public API at https://udb-api.lightsage.dev/ with documentation located at https://udb-api.lightsage.dev/docs/
